# Changelog

## 0.1.0

- Initial release.
- Pass-through: small plants (bushes, pickables, crops, saplings) no longer block characters.
- Step-up: walk onto low obstacles without jumping. Max height per movement mode (walk 0.7 m, run 1.2 m, sprint 1.5 m). Rise speed 6 m/s.
  Uses the player's body shape and lifts by position. DebugLog option.
- Settings sync from servers that run the mod (Jotunn, admin-only).
